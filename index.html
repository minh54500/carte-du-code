carte-du-code

La carte de ton code en une commande : pages, composants, données, base, serveur et outils, avec qui utilise quoi. Un fichier pour ton assistant IA, un graphe « cerveau » pour toi. Your project's code map in one command.

Exemple : un site de restaurantAstro + Supabase + Vercel : pages, tables avec leurs droits, fonctions serveur, tâches planifiées. La carte de cet outilcarte-du-code sur lui-même : ses modules, qui utilise quoi, les fichiers sensibles.

English: restaurant example · this tool's map

Clic sur un point : tout son chemin s'allume. Essaie Colonnes, Santé et la recherche.

npx github:minh54500/carte-du-code          # la carte du dossier courant, dans docs/carte/
claude mcp add carte -s user -- carte mcp   # Claude Code interroge la carte directement
